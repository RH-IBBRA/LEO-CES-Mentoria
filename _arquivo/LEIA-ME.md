# Conteúdo do conceito anterior (arquivado)

Estas páginas são do conceito anterior do site — o blog editorial "Leonardo Ces,
educação para Financial Advisors", com as 5 frentes de conteúdo e identidade
verde/creme/dourado.

Foram arquivadas aqui porque o briefing de **08/09/2026** definiu outra coisa:
a marca passa a ser **oPlanejador**, e o escopo da primeira versão é uma página
inicial com seções (apresentação, para quem é, pilares, canais, materiais, sobre
e contato). Páginas de conteúdo só devem ser criadas quando houver material real
aprovado por Leonardo.

Pontos importantes:

- **Os textos destes artigos eram exemplos (placeholder)**, não conteúdo aprovado.
  Por isso não foram reaproveitados: o briefing proíbe prometer o que ainda não
  existe.
- A pasta `_arquivo/` está no `.vercelignore`, ou seja, **não vai para o ar**.
- Estas páginas apontam para `../assets/style.css`, que foi reescrito com a
  identidade nova. Elas não renderizam mais com o visual antigo. A versão original
  completa (HTML + CSS + JS) está preservada no histórico do git, no commit
  `cbc8738` e anteriores.

Se algum destes textos for aproveitado no futuro, o caminho é reescrevê-lo como
conteúdo real dentro da estrutura nova, com aprovação de Leonardo.
